# Integrated Demonlist
Simple [Pointercrate](https://pointercrate.com/demonlist/) and [Pemonlist](https://pemonlist.com) integration.

## Features
- A new button in the level search screen that opens the demon list
- A search box that allows you to search for a demon in the list by name
- Page navigation buttons that allow you to navigate through the list
- Buttons that allow you to switch between the Pointercrate (For classic demons) and the Pemonlist (For platformer demons)
- Text on a demon's level cell that states its position on the list, with a star icon for classic and a sickle/moon icon for platformer (If on the list and the text is enabled in the mod settings)
- Clickable verifier info on ranked classic demons that opens the verifier's profile
